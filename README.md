# File Transfers

A small, organized home for moving reusable work between devices.

## What is here

| Folder | Purpose |
| --- | --- |
| `skills/` | Complete Codex skills, ready to copy into a personal skills folder. |
| `transfers/` | Future device-to-device files. Use a dated, clearly named subfolder for each transfer. |

## Included skills

- **prompt-execution** — automatically helps Codex carry action-oriented requests through to a completed result.
- **prompt-maker** — automatically helps Codex create strong, ready-to-paste prompts, with GPT-6 Astra defaults.

## Install on another Mac or PC

Download or clone this repository, then copy the desired folders from `skills/` into your Codex skills folder:

```text
~/.codex/skills/
├── prompt-execution/
└── prompt-maker/
```

Restart Codex or start a new task after copying. Each skill includes its own `SKILL.md` and UI metadata.

## Adding transfers

Keep shared files tidy:

1. Create a folder under `transfers/` named `YYYY-MM-DD-short-topic`.
2. Add a small `README.md` that states what the files are and where they belong.
3. Do not place passwords, API keys, or private personal data in this public repository.
